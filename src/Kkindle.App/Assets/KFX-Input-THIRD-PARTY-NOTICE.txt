Project and source package:
https://www.mobileread.com/forums/showthread.php?t=291290

The distributed plugin ZIP contains its corresponding source code. The GNU GPL
v3 license text is included with the bundled Calibre runtime in Calibre\LICENSE.

Kkindle installs this plugin into its isolated Calibre configuration directory
and invokes Calibre as a separate helper process. Kkindle does not include or
install DRM-removal software.
